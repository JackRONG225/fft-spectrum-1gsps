# 架构

一句话：一条纯流式的定长流水线。没有状态机握手，没有背压，帧界由外部相位计数器对齐，
每 8.192 µs 吃掉 8192 个复数样点、吐出四个数（频点、带宽、幅度、帧长）。

---

## 1 数据流

```
                  clk1 = 250 MHz                                │   clk2 = 125 MHz
                                                                │
  ROM 96b/2048  ──► fe4lane ──► ┌ fft2048_core ×4 ┐ ──► comb4 ──► mag_sq24 ×4 ──► 谱RAM ──► ds4 ──► report_fmt4 ──► uart_tx
  (4 lane × 12b    加窗/置换     └ 各 2048 点流水  ┘    radix-4    平方 / 24b      双bank   平滑/走查/      11 键值对     115200 8N1
   I + 12b Q)      J_OFF 对齐       缩放 1/32         3 复乘/拍   饱和             真双口  跨DC合并      84–89 B/行
                                                    出 4 bin/拍
                                └──────────── 写口 clk1 ────┘        └── 读口 clk2 ──┘
                                                  跨域只此一处：真双口 BRAM 的两个时钟端口
```

三处结构要点：

1. **ROM 双口**：一口存 2048 × 96 bit 回放数据（每拍 4 个 lane，每 lane 12 bit I + 12 bit Q），
   另一口存 2048 × 48 bit Hann 系数，4 条 lane 共用。前级无停顿、无背压。
2. **谱 RAM 双 bank**：16 个 1024 × 16 真双口 BRAM（合 8 个 tile），地址最高位即帧 bank。
   写地址 `waddr = {wbuf, kd3[10:2]}`，读地址 `raddr = {rbuf, ra}`。一帧写、一帧读，`wbuf` / `rbuf` 互斥。
   双 bank 不额外花 BRAM——这 8 个 tile 本来就在 41 片的总数里。
3. **跨域只跨谱 RAM**：写口在 clk1、读口在 clk2，真双口 BRAM 的独立时钟端口天然隔离，
   不需要握手、不需要异步 FIFO。`buf_done` 一类单比特事件经两级触发器同步后使用。
   数据通路本身不跨域。

## 2 为什么这么切时钟

`ds4` 要做 256 bin 的前缀差滑窗、全帧峰值跟踪和一次环形左右走查——控制逻辑深、扇出大。
放在 250 MHz 下它曾是全设计的最差路径；而它的吞吐需求只有每帧一次（8.192 µs 内跑完 587 个
clk2 拍），125 MHz 绰绰有余。

于是：**采集与变换（必须快）留在 250 MHz，判决与输出（形状复杂但慢）降到 125 MHz。**
两路时序各自独立收敛，这正是 clk2 的 +0.197 ns 成为全设计最紧、而 clk1 还有 +0.351 ns 的原因。

## 3 模块职责

| 模块 | 职责 | DSP | 时钟域 |
|---|---|---|---|
| `fe4lane` | 地址置换 64×32、Hann 12×12 加窗、`J_OFF=1825` 槽对齐、单 lane 幅度两级流水 | 8 | clk1 |
| `fft2048_core` ×4 | Bailey 4-step 2048 点流水线 FFT，固定缩放 1/32，输出槽 j 载第 `bitrev11(j)` 个频点 | 60（15/核） | clk1 |
| `comb4` | 输出侧 radix-4 合并，每拍 4 个 bin、3 个复乘、`>>2` 饱和 | 9 | clk1 |
| `mag_sq24` ×4 | 13 bit 截位平方、26 bit 求和、24 bit 饱和输出 | 2/路 | clk1 |
| 谱 RAM | 16 × 1024×16 真双口 BRAM（8 tile），地址最高位为帧 bank，双 bank 乒乓 | 8 tile | 写 clk1 / 读 clk2 |
| `ds4` | 256 bin 前缀差平滑（pass A 586 拍）、`thr = PEAK>>1`、PA/PB 双引擎、左右各 4 组/拍、跨直流合并 | 2 + 打包 smem（128×64，LUTRAM） | clk2 |
| `report_fmt4` | 11 个键值对报文模板（含 DCNT）、十进制转换、`FRM=` 收尾 | 纯逻辑 | clk2 |
| `uart_tx` | 115200 8N1 发送，84–89 B 一帧 | 纯逻辑 | clk2 |
| `sys4_top` | 全链顶层（例化上面这些） | — | 双域 |
| `board_top_4lane` | 板级顶层：MMCM + 复位同步 + 全链 + UART + 心跳灯 | — | 双域 |

另有 `complex_multiply2_k.vhd`（3 乘法复乘器，被 4 个核与合并级共用）、
`xadc_temp.v` 与 `ooc250_top.v`（备查，不参与综合）。

**名字怎么读**：`sys4` = 4 lane 的整机，不是"第 4 版"；`fe4lane` = front-end 4 lane；
`comb4` = combine 4；`ds4` = decision stage 4；`mag_sq24` = magnitude squared, 24 bit；
`u` 在 `iq4_u100_full` 里是 unconditional（满带满功率），不是 MHz。

## 4 输出侧 radix-4 合并（本设计的结构核心）

4 个核各作一路 2048 点变换，它们的输出**不是** 8192 点谱的连续四段，而是按对 4 取模的四个同余类。
设一帧样点按 4 相分离写成 `x[4m+l]`，第 l 条 lane 的变换记为 `Yl[k]`，由 DFT 定义展开得

```
X[k] = Σ_{l=0..3}  W_8192^(l·k) · Yl[k mod 2048]          W_N = e^(-j2π/N)
```

把频率单元写成 `k = k0 + 2048q`（q = 0..3），旋转因子分解为
`W_8192^(l(k0+2048q)) = W_8192^(l·k0) · (-j)^(l·q)`，于是

```
Zl  = Yl[k0] · W_8192^(l·k0)          (l = 1,2,3)      Z0 不乘
X[k0 + 2048q] = Σ_{l=0..3}  Zl · (-j)^(l·q)
```

右端是一个 4 点 DFT，即一级 radix-4 蝶形。**每拍只算 Z1、Z2、Z3 三个复乘**，蝶形只剩加减与 (-j) 旋转，
因此每拍 3 个复乘、输出 4 个频率单元，合并级只要 9 个 DSP 而不是两级 radix-2 的 12 个。

写谱地址由三段拼接，不含乘法器：

```
bin = 2048q + 4g + h ,   q ∈ [0,4), g ∈ [0,512), h ∈ [0,4)
```

其中 `k0 = 4g + h`，`h` 是 k0 的低 2 位（跨拍先遍历 h）、`q` 为象限、`g` 为组号。
2048 拍写满 8192 个 bin，与帧节拍一一对应。

> 索引对齐是本设计最容易错的地方：`k0 = bitrev11(j)` 写错时，谱形"看起来仍然对"，
> 只有逐 bin 对拍才抓得住。见 [`metrics.md`](metrics.md) D2/D3 与 `sim/scan7.py`。

## 5 位宽链与缩放

| 环节 | 位宽 | 缩放 / 饱和 |
|---|---|---|
| IQ 输入 | 12 bit 有符号 | — |
| Hann 加窗 | 24 bit 乘积 → 右移 12 → 12 bit 量级 | 移位 |
| 核内复乘 | 18 bit Q1.16 旋转因子；中间乘积 **43/44 bit** | **移位前不截断** |
| 核输出 | 固定缩放 1/32 | 逐级固定，块浮点不参与 |
| 合并蝶形 | 26 bit 求和 | 右移 2 位，饱和回 24 bit |
| 平方谱 | 13 bit 截位平方、26 bit 求和 | 24 bit 饱和输出 |
| 平滑 / 门限 | 256 bin 滑动和右移 8；`thr = PEAK >> 1` | 退化为一次 16 bit 无符号比较，**全设计无除法器、无开方器** |

"移位前不截断"是 3 乘法版与 4 乘法版逐位相同的原因。截断点一旦前移一位，结果就会在低位差 LSB，
而低位差异在 256 bin 平滑与门限比较后仍然可能翻转判决。

## 6 帧节拍与连续捕获

一帧 2048 个 clk1（= 1024 个 clk2），8192 个复数样点，帧周期 8.192 µs。

与改版前的区别只有调度，不改算术：

- `wr_ok` 恒为 1，每个 `fend` 都翻转 `wbuf` 并把 `buf_done` 交给读侧——写口不再在分析期间关闭；
- 读侧仍是"空闲才启动"，忙不过来就整帧跳过。这是**丢帧式**而不是背压式，入口始终 1 GSPS；
- 下游拆成 pass A（平滑，每帧固定 586 拍）与 pass B（峰值向两侧走查，数据相关，最坏 517 拍）。
  同一帧内 pass B 在 pass A 之后，但 pass B(k) 与下一帧的 pass A(k+1) 重叠，故稳态吞吐由
  `max(PA, PB)` 而不是两者之和决定。

判据是 `max(PA, PB) ≤ 1024`（一帧 1024 个 clk2）。586 与 517 都落在预算内，所以 N=1 对任意输入成立，
稳态 done 间隔恒为 1024 个 clk2。**占空比 100% 买到的是调度，不是算力**——DSP 与 BRAM 一个没加。

## 7 报文

11 个键值对，顺序固定：`BW / C / A / L / R / PEAK / THR / FOUND / FRM / DCNT / LAT`，
每行 84–89 B，115200 8N1 发送。满带向量在板上的实际报文：

```
BW=8192 C=4096 A=132 L=0 R=8191 PEAK=341 THR=170 FOUND=1 FRM=8192 DCNT=11678 LAT=17024
```

换算：绝对频率 `fk = k·Δf`，`Δf = 122.070 kHz`。故 `BW=8192` 对应 1000.0 MHz、`C=4096` 对应 500.0 MHz。
`LAT` 直接给分析处理时间（ns），`DCNT` 两次之差给帧周期——一条不依赖 ILA 的帧周期证据链就是这么来的。

`A` 是 done 那拍采的瞬时 I²+Q²，随锁存相位而变，**只作辅助观测、不参与判决**；本设计不设逐样点波形存储与触发。

## 8 缺陷与修复（读源码时会撞到的两处）

**缺陷 10 — 合并级索引偏移。** `J_OFF` 从 1009 改到 1825。1009 + 816 = 1825；11 bit 位反序后，
"固定槽差"变成"按位重排"，于是偏差随 bin 跳变——单点测试全过，只有 8 点扫描才暴露。
定位方法：看偏差随 bin 的跳变模式是否与 bitrev 一致。

**缺陷 11 — `stg*` 多驱动。** `ds4.v` 里打包 smem 的写口曾由两段 always 驱动。
修法是写口只由一段驱动（源码注释 `single driver: this block only`）。

这两条是"仿真过了、上板错"的典型：都能通过单点测试，都要靠全 bin 扫描或逐 bin 对拍才抓得住。
`sim/scan7.py` 就是为第一类缺陷留的安全网。
