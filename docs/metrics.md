# 指标与出处

本文给出一张可逐行核对的表：**每个数字 → 它是怎么来的 → 到哪里去查**。

## 证据等级

| 等级 | 含义 | 可信度边界 |
|---|---|---|
| **L1** | 结构推导 | 由式子在纸上算出。不依赖工具，也不依赖板子。可被任何懂 FFT 的人复核 |
| **L2** | 工具报告 | Vivado 2020.2 的时序/资源报告。可复现：同 RTL、同器件、同指令重跑得同值 |
| **L3** | 行为级仿真 | xsim behavioural，RTL 与定点模型逐字段 / 逐 bin 比对。**不覆盖综合后的时序行为** |
| **L4** | 板级实测 | 板上串口报文 + 抓包日志。是唯一能称为"实测"的等级 |

报告 = `设计报告_1000MSPS.pdf`（64 页，Release 附件）。
报告文件 = 本仓库 `docs/reports/` 下的 `.rpt`，行号为该文件内的行号。

## A · 吞吐与时间

| # | 指标 | 值 | 等级 | 报告出处 | 报告文件 · 行号 |
|---|---|---|---|---|---|
| A1 | 数字吞吐 | 4 × 250 MHz = 1 GSPS，每拍 4 个复数样点 | L1 + L4 | §1.2 表 1-1；§2.4 | — |
| A2 | 帧长 | 8192 点 = 2048 个 clk1 = 1024 个 clk2 = **8.192 µs** | L1 + L4 | §3.5 表 3-7 | — |
| A3 | 结果更新周期 | 1024 个 clk2 = 8.192 µs（N=1）；板上 DCNT 实读 8.1920 µs | L4 | §5.3、§5.6 表 5-5 | — |
| A4 | 分析处理时间上界 | 2132 个 clk2 = **17.1 µs** = 1024 + 3 + 587 + 517 + 1 | L1 | §3.5 表 3-7 式 (3-8) | — |
| A5 | 分析处理时间实测 | 报文 LAT 域 **2128 拍 = 17.024 µs**，60 s 抓包 7858 行恒值 | L3 + L4 | §5.4 表 5-4 | — |
| A6 | 频率分辨率 | Δf = 1 GSPS / 8192 = **122.070 kHz** | L1 + L3 | §5.3.1 式 (5-2) | — |
| A7 | pass A / pass B | PA 固定 586 拍（预算记 587）；PB 最坏 517 拍；五向量 22/122/308/327/380 | L1 + L3 | §4.1、§3.5 | — |

**A4 的算式**：一帧采集 1024 + 帧界→ds_start 3 + pass A 587 + pass B 517 + 锁存/CDC 1 = 2132 个 clk2。
2132 / 125 MHz = 17.056 µs，取 17.1 µs。实测 2128 拍，比上界少 4 拍（跨域同步与交接），
说明上界是紧的、不是过估。

**A1 的口径**：1 GSPS 是**数字吞吐**。板上无 1 GSPS ADC，激励为片内 ROM 回放（2048 × 96 bit，
每拍 4 个 lane × 12 bit I + 12 bit Q）。任何"采样率 1 GSPS"的表述都是错的。

4 个 FFT 核 × 15 = 60，`comb4` 9，`fe4lane` 8，4 路 `mag_sq24` × 2 = 8 → 60 + 9 + 8 + 8 = **85**。

## C · 功能指标

| # | 指标 | 值 | 等级 | 报告出处 | 备注 |
|---|---|---|---|---|---|
| C1 | IQ 位宽 | 12 bit（ROM 单口 96 bit = 4 lane × {Q, I}） | L3 + L4 | §3.4 表 3-6 | 全链固定缩放 1/128 |
| C2 | FFT 点数 | 8192 = 4 × 2048，输出侧 radix-4 合并 | L1 + L3 | §4.3 式 (4-1) | 4 个核各给同余类，不是连续四段 |
| C3 | 数字 IQ 带宽（申报值） | **768.55 MHz** = 6296 bin × 122.07 kHz（板测，跨直流） | L1 + L3 + L4 | §5.3.3、表 5-2 | 880 MHz 向量；相对理论值 780 MHz 低 1.47% |
| C4 | 可测带宽边界 | **0.80 – 0.86 GHz** | L1 + L3 | §3.3、§5.3.3 | 判据：定点模型与 RTL 是否仍能互证 |
| C5 | 满带结构能力 | 8192 bin = 1000 MHz（满带向量板测读得） | L4 | §5.4 | 结构能力，不等于带限信号的可测带宽 |
| C6 | 3 乘法 Karatsuba | 单核 20 → **15** DSP；全链 105 → **85** | L1 + L2 | §4.2、§6.1 | 位精确：中间 43/44 bit，移位前不截断 |

**C3 的算式**：6296 × 122.070 kHz = 768.55 MHz。（早期草稿曾写作 2296 bin，那是笔误：2296 × 122.07 kHz ≈ 280 MHz，
与 768.55 MHz 不符。）

**C4 的来由**：256 bin 的平滑窗在 1 GSPS 下等于 31.25 MHz 的平滑宽度，占 780 MHz 向量的 4%，
−3 dB 边界被抹平后定位误差增大。所以"可测"止步于 0.80–0.86 GHz，再往上模型与 RTL 无法逐 bin 互证。
这是**判据的边界**，不是器件的上限。

## E · 草稿与报告的四处不一致（已定稿）

对外统一取**报告 + 原始 rpt 能互证**的那一版。表里的"草稿旧值"是早期草稿的笔误，不采用，
列在这里是为了让读者遇到旧版本材料时能对上号。

| # | 项目 | 草稿旧值 | 定稿值 | 依据 |
|---|---|---|---|---|
| E1 | LUT / FF 百分比 | 41.6% / 41.3% | **61.63% / 51.25%** | util 行 34 / 39：12819/20800、21320/41600 |
| E2 | 带宽 bin 数 | 2296 | **6296** | 表 5-2；6296 × 122.07 kHz = 768.55 MHz |
| E3 | 宽带逐位相同 bin | 6043 / 8192 | **6506–6511 / 8192** | 报告 §5.5 |
| E4 | 占空比判据 | `max(PA,PB) ≤ 1024` 与 `≤ 586` 两处并存 | **PA 586 / PB 517 / 一帧预算 1024** | 表 1-1 与表 5-4 |

E4 不是矛盾：1024 是一帧的拍数预算，586 与 517 是 pass A / pass B 各自的最坏长度，
两个都在预算内，所以 N=1 成立。混写成一个数才会自相矛盾——这也是本仓库统一写成三分量的原因。

若哪天发现草稿才是对的，要改的是**报告与 rpt**，不是本文：L2 原始报告就摆在
`docs/reports/` 里，改文档不改报告只会让两者更对不上。

## F · 未验证项（不写进任何指标表）

1. 综合后仿真、实现后时序仿真：**未做**。
2. ILA 在线抓取：**未做**（1G 档资源与时序都不允许插入探针）。
3. 跨 Vivado 版本：**未验证**（换版本必须重跑策略扫描）。
4. 小时级老化 / 变温复采：**未做**（板级只有 60 s 量级抓包）。
5. 700 MHz 向量的板级读数来自上一代 N=2 网表，不是 v11 板测。
6. 模拟前端与系统级闭环：**不存在**。
